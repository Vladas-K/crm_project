# Noto Sans для документов CRM

`NotoSans-Regular.ttf` и `NotoSans-Bold.ttf` используются и встраиваются в PDF тайминга для поддержки кириллицы без системных шрифтов.

Источник: https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans

Лицензия SIL Open Font License 1.1 сохранена в `LICENSE`. Шрифты не изменены.
